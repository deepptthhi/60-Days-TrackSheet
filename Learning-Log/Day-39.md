# Day 39 - Learning Cloud Computing Basics

## What did I learn?

Today, I started learning **Cloud Computing**, which is an important part of modern backend development, DevOps, and SRE. After completing Linux and Computer Networks, I understood that cloud platforms provide the infrastructure required to run applications without companies having to maintain all the physical hardware themselves.

I learned that **Cloud Computing** provides resources such as servers, storage, databases, networking, and computing power over the Internet. I also learned about major cloud providers such as **AWS, Microsoft Azure, and Google Cloud**.

I then learned about the different **cloud deployment models**—Public Cloud, Private Cloud, and Hybrid Cloud. I understood that public cloud resources are provided by cloud companies, private cloud infrastructure is dedicated to an organization, and hybrid cloud combines both approaches.

Another important concept was **IaaS, PaaS, and SaaS**. I understood that IaaS provides infrastructure such as virtual machines, PaaS provides a platform for deploying applications without managing much of the underlying infrastructure, and SaaS provides ready-to-use software such as Gmail or Microsoft 365.

I also learned about **Regions and Availability Zones**. A region represents a geographical area containing cloud infrastructure, while Availability Zones are isolated locations within a region. Using multiple Availability Zones helps applications achieve higher availability and continue working even if one location fails.

Another concept I understood was **scalability and elasticity**. Vertical scaling means increasing the power of an existing server, while horizontal scaling means adding more servers. Elasticity allows cloud resources to automatically increase or decrease depending on demand.

I also learned the basics of **cloud storage and computing**. Object storage is useful for files such as images and videos, while virtual machines such as AWS EC2 provide computing resources for running applications.

Towards the end of today's learning, I explored basic **cloud networking and security** concepts such as VPCs, Security Groups, and IAM. I understood that a VPC provides an isolated network environment, Security Groups control network traffic to resources, and IAM manages users, roles, and permissions.

I also learned about **monitoring and the Shared Responsibility Model**. Cloud providers manage the underlying physical infrastructure, while customers are responsible for things such as their applications, data, permissions, and configurations.

By the end of today's learning, I understood how cloud computing provides the foundation for modern applications and why technologies such as AWS, Docker, Kubernetes, and CI/CD are commonly used together in DevOps and SRE environments.

## What challenges did I face?

The biggest challenge today was understanding the difference between **IaaS, PaaS, and SaaS**. At first, they seemed similar, but comparing how much infrastructure the customer manages in each model made the difference clearer.

I also found it slightly confusing to differentiate between **scalability and elasticity**. I understood that scalability is the ability to handle increased workload, while elasticity focuses on automatically adding or removing resources based on demand.

Another challenge was understanding how **Regions and Availability Zones** work together. Visualizing multiple isolated Availability Zones inside a Region helped me understand how cloud platforms provide high availability.
